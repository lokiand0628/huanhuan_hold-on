## 简介

普通的提醒软件治不了久坐，因为**提醒是能被反射性关掉的** —— 弹出来，眼睛扫一眼，手指顺手一划，继续工作。

**缓缓**把这点当成核心问题来解决。每个任务可以独立选择提醒强度：

- **居中浮窗**（默认）：桌面正中弹出一个无边框小窗，置顶、不进任务栏，**点「确认」才消失**，不确认就一直待在那儿。
- **锁屏强制**：全屏接管所有显示器、抢回焦点，**重启也逃不掉**。休息时长记在墙上时钟上，关机重来那几分钟照样算数。

它不是「通知你一下」，是让你真的站起来。

> **平台**：仅 macOS，且仅 Apple Silicon（M 系列）。Windows / Linux / Intel Mac 都没有构建产物。

## 为什么你需要它？

### 1. 真的能让你休息

- **两种强度按任务选**：喝水、护眼这类「提一句就行」的任务用居中浮窗；久坐这种「不站起来不行」的用锁屏强制。不必为了一个任务把整个软件变成暴君。
- **居中浮窗也关不掉**：它不是一个普通弹窗 —— 无边框、置顶、不进任务栏、没有关闭按钮，`Cmd+W` 也拦掉。只有「确认」和「推迟 N 分钟」两个出口。
- **多显示器全覆盖**：锁屏时扩展屏和镜像屏一起接管，防止你转到副屏继续工作；中途插拔显示器会自己补齐。
- **强制档位**：登录项 + 后台守护 + 状态落盘 + 墙上时钟。锁定期间 **`Cmd+Q`、托盘退出、Cmd+Tab 全部无效**。
- **重启也不算逃**：休息进度写在磁盘上，用的还是系统时钟。强制关机重启花掉的时间照算 —— 拔电源省不下那几分钟。
- **改时钟也没用**：每十秒落一次单调检查点，把手动把系统时间往回拨并不会让休息变短。

### 2. 贴心不打扰

- **提前预告**：每项任务可独立设置提前几秒给出预警，让你先把手里那半句话说完。
- **可控推迟**：推迟时长每项任务可设。但推迟只给一次 —— 软提醒和锁屏强制都是，推迟到点再弹出来的那一次就只剩「确认 / 完成休息」一个出口。
- **离开电脑就重新计时**：人不在的时候不该催你休息，回来后也不会立刻被弹一脸。
- **休息时处理视频音乐**：不处理 / 只暂停视频 / 全部暂停，三档，默认不打断音乐。
- **静默自启**：随系统登录启动并直接待在托盘，不在开机时弹窗。

### 3. 简单好用

- **完整的任务系统**：内置久坐、喝水、护眼，也可添加任意自定义任务，多项提醒彼此独立并行。
- **两种调度**：每隔若干分钟触发，或每天固定多个时间点，例如 11:00 运动、21:00 泡脚。
- **任务级控制**：每项任务独立启停、暂停、重置，并配置间隔、提醒方式、休息时长、预告、推迟时长。
- **休息时长随便设**：秒 / 分钟 / 小时三档单位，最长 12 小时。想休息两小时就选「小时」敲个 2，不必按 119 次加号。**把时长改大到 10 分钟以上要先过指纹或开机密码**，往小改则不用 —— 「今天想轻松点」不该被自己的工具拦住。
- **快捷批量操作**：主界面和托盘都支持全部暂停 / 继续 / 重置，托盘还能单独重置某个任务。
- **后台精准计时**：计时跑在 Rust 后端线程上，不受窗口最小化或 macOS App Nap 节流影响。
- **实用托盘菜单**：显示主窗口、暂停或继续、重置任务、重启与退出；托盘悬停会列出各项剩余时间。

## 下载与安装

前往 [GitHub Releases](https://github.com/lokiand0628/huanhuan_hold-on/releases) 下载 `Huanhuan_0.0.3_aarch64.dmg`，打开后把「缓缓」拖进「应用程序」。

（本地自己打包的话，产物名还是 `缓缓_0.0.3_aarch64.dmg` —— 带中文名传上 GitHub 会被抹成 `_0.0.3_aarch64.dmg`，所以发布流程里改成了 ASCII 的。）

### 首次打开被 macOS 拦下怎么办

这个包**没有 Apple 开发者签名，也没有公证**（个人项目，不做每年 99 美元的账号）。所以第一次打开会弹「无法验证开发者」或「已损坏」。两种解法，任选其一：

```bash
# 解法一：去掉下载隔离标记（推荐，一次就够）
xattr -dr com.apple.quarantine /Applications/缓缓.app
```

解法二：在「访达」里右键点「缓缓」→ 选「打开」→ 在弹窗里再点一次「打开」。

> 这不是出问题了，是 Gatekeeper 对所有未公证应用的默认态度。介意的话可以自行从源码构建 —— 见下一节，自建出来的包在你机器上不会被拦。

## 从代码构建

需要 Rust 工具链与 Node.js。**构建目标是 Apple Silicon**。

### 1. 开发环境运行

```bash
# 安装依赖
npm install

# 启动开发服务器与应用
npm run tauri dev
```

只想调界面时，可以直接 `npm run dev` 并在浏览器打开 `http://127.0.0.1:5173/?mock=1` —— 会挂上一套假后端（计时是真的，只有窗口和系统调用是假的），改样式时不必反复重启 Rust。

### 2. 生成安装包

```bash
# 构建 Apple Silicon 的 dmg
npm run tauri build -- --target aarch64-apple-darwin --bundles dmg
```

## 检查更新

设置页有个「检查更新」，它**只查、不装**：问一次 GitHub 上有没有更新的 tag，有就把你送到 release 页面自己下。

这么做是有意的。上一版用的是一套自动下载安装的更新器，那需要一对签名密钥；密钥不在手上，留着它反而可能把人引去装成别的包。少了一点省事，换来的是不用保管私钥，也不会装错东西。

## 版本记录

### v0.0.3 (2026-10-11)

修掉几个手测才发现的问题。

- **锁屏强制的「推迟」不再可以无限点**：推迟资格从前记在 `lock.json` 里，而点一次推迟会结束整场锁、连文件一起删掉 —— 于是每一轮都从满格重新开始，「还能推迟 3 次」永远不变、想点几次点几次。现在推迟**只给一次**，和软提醒同一条规则：推迟到点再弹出来的那一次只剩「完成休息」。任务设置里的「最多推迟几次」随之移除 —— 没有次数可配了。
- **居中浮窗点一下「知道了」就能关**：macOS 的 WebView 默认不接收未激活窗口上的第一次点击（那一下只拿来把窗口带到前台），所以要点两下。浮窗现在开了「第一次点击直接生效」。
- **确认过的提醒不再「哑掉」**：点「知道了」/「推迟」时，代码先把浮窗关掉再上报后端 —— 窗口一没，上报就静默丢失，那条提醒的 `triggered` 卡住，此后**永远不会再响**（要重启才恢复）。现在顺序倒过来：先结清、后关窗。

### v0.0.2 (2026-10-10)

修复

- 删空所有任务后重启，三个内置任务会自行恢复（空列表应保持为空）
- 居中浮窗四周多出一圈方形灰边 —— 系统阴影按窗口矩形绘制，不认卡片圆角
- 居中浮窗启动瞬间先闪出一个不透明矩形
- 弹出提示会清掉所有输入框的焦点与未提交的草稿
- 「稍后再说」按钮上的 `(2)` 被误读为倒计时；软提醒改为只给一次推迟
- 紧急闸门敲错字符时界面没有任何反馈，现在错处标红
- 空闲状态标志位恒为 `false` —— 后端一直在发事件，前端从未监听
- 闸门进度不落盘，`lock.json` 的 `gate_matched` 恒为 0
- 发布脚本改 dmg 附件名时取错资产 id（`node_id` 而非数字 id，返回 404 而非 400）

「每天几点」的输入

- 冒号可选：`22:00`、`2200`、`22`、`9` 等价
- 回车即加入，光标留在输入框内；`9,12,18` 可一次粘贴全部加入
- 切换到该模式时自动聚焦输入框
- 内容为空时提示「先选一个时间」，不再一律报格式错误
- 展开的定点任务不再重复渲染卡顶的时间芯片

其它

- 设置页「关于」新增「关于作者」与「快捷标星」
- 仓库地址收敛到 `src/core/links.js` 单一来源
- 清理死代码：17 条无引用文案、4 条死 CSS 规则及若干空转函数与导出

### v0.0.1 (2026-10-09)

首个公开发布版。相对上游是一次前端重写 + 后端清理，配置自动迁移。

- 提醒强度按任务选：居中浮窗 / 锁屏强制（旧版只有全局开关）
- 锁屏强制：256 字符紧急出口（拦粘贴、不可选中）、进度落盘 + 墙上时钟、拦截 `Cmd+Q` 与托盘退出、单实例
- 休息时长支持秒 / 分钟 / 小时，上限 12 小时（旧版 600 秒）；加到 10 分钟以上需 Touch ID 或开机密码
- 主窗口缩成两页（提醒 / 设置），删除概览页、悬浮窗子系统与英文界面
- 修复概览页表盘数字不渲染、任务卡步进切页回退、紧急解锁闸门不出现、锁屏表盘弧度为 `NaN`
- 界面按 Duolingo 设计规范重做，Nunito 本地打包，数字等宽
- 应用改名 `缓缓`，图标换成暂停标记
- 检查更新改为只查不装
- 仅发布 macOS (Apple Silicon)
