## 简介

普通的提醒软件治不了久坐，因为**提醒是能被反射性关掉的** —— 弹出来，眼睛扫一眼，手指顺手一划，继续工作。

**缓缓**把这点当成核心问题来解决。每个任务可以独立选择提醒强度：

- **居中浮窗**（默认）：桌面正中弹出一个无边框小窗，置顶、不进任务栏，**点「确认」才消失**，不确认就一直待在那儿。
- **锁屏强制**：全屏接管所有显示器、抢回焦点，**重启也逃不掉**。休息时长记在墙上时钟上，关机重来那几分钟照样算数。

它不是「通知你一下」，是让你真的站起来。

> **平台**：仅 macOS，且仅 Apple Silicon（M 系列）。Windows / Linux / Intel Mac 都没有构建产物。

## 为什么你需要它？

### 1. 真的能让你休息

- **两种强度按任务选**：喝水、护眼这类「提一句就行」的任务用居中浮窗；久坐这种「不站起来不行」的用锁屏强制。不必为了一个任务把整个软件变成暴君。
- **居中浮窗也关不掉**：它不是一个普通弹窗 —— 无边框、置顶、不进任务栏、没有关闭按钮，`Cmd+W` 也拦掉。只有「确认」和「推迟 N 分钟」两个出口。
- **多显示器全覆盖**：锁屏时扩展屏和镜像屏一起接管，防止你转到副屏继续工作；中途插拔显示器会自己补齐。
- **强制档位**：登录项 + 后台守护 + 状态落盘 + 墙上时钟。锁定期间 **`Cmd+Q`、托盘退出、Cmd+Tab 全部无效**。
- **重启也不算逃**：休息进度写在磁盘上，用的还是系统时钟。强制关机重启花掉的时间照算 —— 拔电源省不下那几分钟。
- **改时钟也没用**：每十秒落一次单调检查点，把手动把系统时间往回拨并不会让休息变短。

### 2. 贴心不打扰

- **提前预告**：每项任务可独立设置提前几秒给出预警，让你先把手里那半句话说完。
- **可控推迟**：每项任务可设置推迟时长与最大次数，次数用完就只剩「完成休息」。
- **离开电脑就重新计时**：人不在的时候不该催你休息，回来后也不会立刻被弹一脸。
- **休息时处理视频音乐**：不处理 / 只暂停视频 / 全部暂停，三档，默认不打断音乐。
- **静默自启**：随系统登录启动并直接待在托盘，不在开机时弹窗。

### 3. 简单好用

- **完整的任务系统**：内置久坐、喝水、护眼，也可添加任意自定义任务，多项提醒彼此独立并行。
- **两种调度**：每隔若干分钟触发，或每天固定多个时间点，例如 11:00 运动、21:00 泡脚。
- **任务级控制**：每项任务独立启停、暂停、重置，并配置间隔、提醒方式、休息时长、预告、推迟策略。
- **休息时长随便设**：秒 / 分钟 / 小时三档单位，最长 12 小时。想休息两小时就选「小时」敲个 2，不必按 119 次加号。**把时长改大到 10 分钟以上要先过指纹或开机密码**，往小改则不用 —— 「今天想轻松点」不该被自己的工具拦住。
- **快捷批量操作**：主界面和托盘都支持全部暂停 / 继续 / 重置，托盘还能单独重置某个任务。
- **后台精准计时**：计时跑在 Rust 后端线程上，不受窗口最小化或 macOS App Nap 节流影响。
- **实用托盘菜单**：显示主窗口、暂停或继续、重置任务、重启与退出；托盘悬停会列出各项剩余时间。

## 设计

界面按 [Duolingo 的品牌设计规范](https://design.duolingo.com/)（Friendly Geometry）实现，不是「差不多圆润」的那种模仿：

- **圆角几何**：所有形状都有圆角，没有尖角；按压控件用「接触式厚度」（`0 Npx 0` 的实心投影）而不是弥散阴影。
- **颜色分工明确**：蓝色 = 可操作 / 选中 / 主按钮，绿色 = 完成与成功，危险色只用于危险动作。身份色只出现在图标和圆点上，绝不铺成按钮底色。
- **数字等宽**：所有倒计时开 `tabular-nums`，跳秒不抖。
- **字体本地化**：Nunito（OFL 协议，已打进包里）+ PingFang SC 回退，不依赖 Google Fonts 在线加载。

## 技术架构

本产品追求极致的内存占用与启动速度：

- **Backend**: [Rust](https://www.rust-lang.org/) (Tauri 2.0) — 计时引擎、锁屏守护、多显示器接管、平台能力。
- **Frontend**: [Vite](https://vitejs.dev/) + 原生 JavaScript（零框架、零运行时依赖）— 命令式 DOM，没有虚拟 DOM 的额外开销。
- **Communication**: Tauri IPC — 前后端异步通信；计时器不依赖界面刷新。
- **Styles**: CSS Variables — 单层 token 体系（surface / ink / accent / state / identity / radius / depth / type / space / motion）。

## 下载与安装

前往 [GitHub Releases](https://github.com/lokiand0628/huanhuan_hold-on/releases) 下载 `Huanhuan_0.0.2_aarch64.dmg`，打开后把「缓缓」拖进「应用程序」。

（本地自己打包的话，产物名还是 `缓缓_0.0.2_aarch64.dmg` —— 带中文名传上 GitHub 会被抹成 `_0.0.2_aarch64.dmg`，所以发布流程里改成了 ASCII 的。）

### 首次打开被 macOS 拦下怎么办

这个包**没有 Apple 开发者签名，也没有公证**（个人项目，不做每年 99 美元的账号）。所以第一次打开会弹「无法验证开发者」或「已损坏」。两种解法，任选其一：

```bash
# 解法一：去掉下载隔离标记（推荐，一次就够）
xattr -dr com.apple.quarantine /Applications/缓缓.app
```

解法二：在「访达」里右键点「缓缓」→ 选「打开」→ 在弹窗里再点一次「打开」。

> 这不是出问题了，是 Gatekeeper 对所有未公证应用的默认态度。介意的话可以自行从源码构建 —— 见下一节，自建出来的包在你机器上不会被拦。

## 从代码构建

需要 Rust 工具链与 Node.js。**构建目标是 Apple Silicon**。

### 1. 开发环境运行

```bash
# 安装依赖
npm install

# 启动开发服务器与应用
npm run tauri dev
```

只想调界面时，可以直接 `npm run dev` 并在浏览器打开 `http://127.0.0.1:5173/?mock=1` —— 会挂上一套假后端（计时是真的，只有窗口和系统调用是假的），改样式时不必反复重启 Rust。

### 2. 生成安装包

```bash
# 构建 Apple Silicon 的 dmg
npm run tauri build -- --target aarch64-apple-darwin --bundles dmg
```

## 检查更新

设置页有个「检查更新」，它**只查、不装**：问一次 GitHub 上有没有更新的 tag，有就把你送到 release 页面自己下。

这么做是有意的。上一版用的是一套自动下载安装的更新器，那需要一对签名密钥；密钥不在手上，留着它反而可能把人引去装成别的包。少了一点省事，换来的是不用保管私钥，也不会装错东西。

## 版本记录

### v0.0.2 (2026-10-10)

修掉 v0.0.1 里几个"用着用着才发现"的问题。

- **删掉的任务不再自己长回来**：删光所有任务后一重启，三个内置任务会重新出现 —— 现在空列表就是空列表。（只有配置里压根没有 `tasks` 这个键，也就是首次启动，才会铺内置任务。）
- **居中浮窗不再是"方框套圆角"**：macOS 给透明窗口画的那层系统阴影是按**窗口矩形**算的，不认卡片自己的圆角，于是卡片四周会多出一圈方形灰边。现在关掉系统阴影，阴影交给卡片自己画。
- **「稍后再说」不再显示 `(2)`**：括号里那个数字是"还剩几次推迟"，但看着像倒计时。软提醒现在**只给一次**推迟，按钮直接写「10 分钟后再提醒你」；推迟时长在 5 分钟或以内时，干脆不显示这个按钮 —— 等于没推，不如不给。（锁屏强制的推迟不受影响，它按任务配的次数来。）
- **紧急闸门会告诉你打错了**：以前敲错一个字母只是被悄悄弹回，界面没有任何反应，只能自己数格子；现在打错的那一下，目标文本里该打的那个字符和输入框边框会**同时变红**。
- **居中浮窗不再先闪一个白方块**：路由属性以前在启动流程的某个 `await` 之后才落下，透明底色晚了几帧才生效，于是浮窗起来时会先出现一个不透明矩形。
- **弹提示不再清掉你正在打的字**：以前每弹一条提示都会整棵重绘，屏幕上所有输入框的焦点和半截草稿一起没。
- **「你离开了，计时停着」这句终于会出现**：Rust 端一直在发空闲状态事件，前端从来没监听，那个标志位永远是 `false`。
- **闸门进度真的会落盘了**：「重启后不用重打」这句话以前是假的 —— `lock.json` 里的 `gate_matched` 从来没有被更新过。
- **发布流程里给 dmg 改名那一步修好了**：v0.0.1 的附件名是手工修补的。根因是 `gh release view --json assets` 给出的 `id` 是 node_id，而资产接口要的是数字 id（只藏在 `apiUrl` 最后一段），拿错了得到的是 **404 而不是 400**，看着像权限问题。
- **「每天几点」这个框终于顺手了**：以前得原样敲出 `22:00`，少一个冒号就判格式错 —— 桌面上敲 `2200` 明明少按一个键。现在 `2200`、`22`、`9` 都收；敲回车直接加进去，不用去够旁边那个按钮，加完光标还留在框里等着敲下一个；粘一串 `9,12,18` 会三个一起加，而不是静默只取第一个。切到「每天几点」时，光标已经先一步落在框里了。
- **空着点「加一个时间」不再冤枉你**：以前一律提示"时间格式不对"，现在没填就说"先选一个时间"，填错才说格式。
- **展开的定点卡不再把同一排时间画两遍**：卡顶那排快捷芯片和展开区里的「提醒时间」是同一批时间点，上下挨着，看着像渲染了两遍。现在定点任务一展开就收起卡顶那排。（间隔任务不收起 —— 那边展开区里是步进器，芯片是"一下点到 30 分"的快捷方式，是不同的东西。）
- **「关于」里有作者了**：加上了「关于作者」（砖头，附项目地址与 GitHub 主页），以及一个「快捷标星」—— 点了开浏览器，并告诉你到了页面上该点哪儿。
- 清掉一批死代码：17 条没人引用的文案、4 条死 CSS 规则、以及若干空转的函数和导出。

### v0.0.1 (2026-10-09)

第一个公开发布版。相对上游项目，这一版是一次**前端重写 + 后端清理**，产品形态有变，**配置会自动迁移**。

- **两种提醒方式按任务选**：居中浮窗（默认，桌面居中的无边框小窗，点「确认」才消失）与锁屏强制。原来只有一个全局「强制模式」开关，现在每个任务自己决定。
- **锁屏强制变成真的强制**：256 个随机字母的紧急出口（拦粘贴、不可选中）；休息进度落盘 + 墙上时钟，重启、`kill -9`、改系统时钟都逃不掉；补上了 `Cmd+Q`、托盘退出/重启的拦截，以及单实例插件。
- **休息时长可以设很久**：秒 / 分钟 / 小时三档单位，上限 12 小时（旧版上限只有 600 秒，「休息 2 小时」根本敲不进去）。往大改到 10 分钟以上要先过 Touch ID 或开机密码，改小免验证。
- **主窗口缩成两页**：提醒 / 设置。删掉概览页与今日计数；删掉悬浮窗子系统（置顶小窗、靠边隐藏、多配色）与英文界面。
- **修了一批「看着生效、其实没生效」的问题**：概览页大表盘数字从不渲染、任务卡数值步进改动切页即回退、紧急解锁闸门永远不会出现、锁屏表盘弧线比例恒为 `NaN`。
- **界面按 Duolingo 设计规范重做**：token 体系重排（蓝色 = 可操作、绿色 = 完成），输入控件统一外观，Nunito 字体本地打包，数字全部等宽。
- **改名与换标**：应用名从 `health-reminder` 改成 `缓缓`，登录项、Dock、二进制名一并跟着走；图标换成「暂停」标记。
- **检查更新改为只查不装**：不再内置自动更新器与签名密钥，有新版就把人送到 release 页面。
- **仅发布 macOS (Apple Silicon)**。
